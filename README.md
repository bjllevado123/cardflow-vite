# CardFlow (Vite)

Local-first rebuild of CardFlow using Vite + Dexie. Original Next.js CardFlow is unchanged.

## Local

```bash
npm install
npm run import:excel
docker compose --env-file .env up -d --build
```

Open http://localhost:3002

Sign in with the same CardFlow account (`llevadob@gmail.com` or `parents@cardflow.app`).
